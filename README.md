# InvestiFull — démonstration Web

Version 0.40.1+40. Ce dépôt public contient uniquement la distribution Web compilée et ses ressources. Le dépôt source de développement reste privé.

Démonstration sans compte, connexion bancaire ni synchronisation entre appareils. Les données saisies restent dans le stockage de ce navigateur selon les consentements choisis dans l'application. Aucune donnée personnelle n'est intégrée à cette distribution.

Le site est servi à la racine du projet /investifull-demo/. Le démarrage utilise les ressources CanvasKit locales et n'enregistre pas de nouveau service worker.

Cette distribution provient du build local 0.40.1 déjà vérifié ; une compilation indépendante de la même version a également réussi sur GitHub Actions. Ne pas confondre la démonstration avec la livraison mobile finale.
